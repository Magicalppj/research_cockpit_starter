# Artifact Ingest Migration In 0.2.0

## Decision

Version 0.2.0 changes `ingest-artifact` for experiment targets from implicit graph-node creation to artifact-record creation. The earlier `--record-only` opt-in remains accepted, but it is no longer required.

This is a deliberate compatibility break for scripts that omitted both mode flags and expected `graph/nodes/artifact_*.yaml` to be created. Those scripts must choose one mode explicitly before upgrading.

## New Contract

Ordinary experiment output:

```sh
research-cockpit ingest-artifact --root <data-root> --node <experiment_id> --from <run-dir> --run-id <run_id> --json --compact --no-build
```

Immediate graph evidence:

```sh
research-cockpit ingest-artifact --root <data-root> --node <node_id> --from <run-dir> --run-id <run_id> --promote --promotion-reason "Durable evidence for decision or baseline" --json --compact --no-build
```

Promotion of an existing record:

```sh
research-cockpit promote-artifact-record --root <data-root> --id <record_id> --artifact-id <artifact_id> --link-to <node_id> --promotion-reason "Durable evidence for decision or baseline" --json --compact
```

`--record-only` remains valid when a caller wants to state record mode explicitly. A non-experiment target must use explicit `--promote --promotion-reason` or `create-artifact`; omission never changes its semantics silently.

## Upgrade Check

1. Search automation for `ingest-artifact` calls that omit both `--record-only` and `--promote`.
2. Keep ordinary experiment output in default record mode.
3. Add `--promote --promotion-reason` only where a graph node is required for durable navigation, a decision, or a baseline.
4. Update `promote-artifact-record` calls to include `--promotion-reason`.
5. Run command discovery and the release guard:

```sh
research-cockpit commands --json --compact --name ingest-artifact
python dev/scripts/run_skill_release_check.py --json --skip-mutating
```

The canonical payload path remains `artifacts/<node_id>/<run_id>/`; only the default metadata representation changes.
